# Sample data

## `orders_sample.csv` / `orders_sample.xlsx` – the main dataset (121 rows)

Generated by `npm run generate:sample` (also by `npm run seed`) **relative to a reference time**,
saved in `orders_sample.meta.json`. Upload it as a manager; for exactly the counts below, open
"Advanced" on the Import page and set _Evaluate as of_ to the reference time (otherwise a few
recent orders may cross a threshold as time passes). The XLSX holds real Excel date cells.

| Planted                                                                                                                                                             | Rows | Expected result                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- | --------------------------------------- |
| Delivered orders                                                                                                                                                    | 30   | no task                                 |
| In transit, delivery date still ahead                                                                                                                               | 12   | no task                                 |
| Unconfirmed < 2 h, confirmed < 24 h, cancelled                                                                                                                      | 18   | no task                                 |
| Unconfirmed 3–30 h                                                                                                                                                  | 8    | UNCONFIRMED_ORDER                       |
| Confirmed 26–72 h, not dispatched                                                                                                                                   | 8    | DISPATCH_DELAY                          |
| Dispatched, delivery date passed (≤ ₹5,000)                                                                                                                         | 8    | SHIPMENT_DELAY                          |
| Failed delivery ("Delivery Failed", "NDR", "Undelivered")                                                                                                           | 8    | FAILED_DELIVERY                         |
| High value (> ₹5,000) in transit and late                                                                                                                           | 6    | SHIPMENT_DELAY + HIGH_VALUE_DELAY       |
| High value confirmed, promised date passed                                                                                                                          | 2    | DISPATCH_DELAY + HIGH_VALUE_DELAY       |
| Failed delivery with unknown employee `EMP009`                                                                                                                      | 2    | FAILED_DELIVERY, **unassigned**         |
| Bad data (missing name/phone, bad phone, 31-02, 32/13, future date, shipped without EDD ×2, value "abc", unknown status, status/date conflict, payment "UPI later") | 14   | needs correction → DATA_CORRECTION task |
| Identical duplicate rows                                                                                                                                            | 2    | skipped                                 |
| Same Order ID twice with different values                                                                                                                           | 2    | both rejected                           |
| Row without Order ID                                                                                                                                                | 1    | rejected                                |

**Totals:** 116 orders stored, 14 need correction, 3 rejected rows, 2 duplicates skipped, **64 tasks**
(8 unconfirmed, 10 dispatch delay, 14 shipment delay, 10 failed delivery, 8 high value, 14 data
correction), 2 of them unassigned. These counts are checked by an automated test.

Employees are referenced by code (`EMP001`), by name (`Priya Sharma`) and by email to show matching.
Dates mix `DD-MM-YYYY HH:mm`, `YYYY-MM-DD HH:mm` and `DD/MM/YYYY HH:mm`; values mix `1299` and `₹1,299`.
